Prompt for Replit

Title: Build a modular school theater web app (Claret Sevilla theme)

Goal: Create a modern, scalable web application for a theater school. It should include a public-facing website (blog, gallery, events), a ticket reservation system (no payments, just PDF with QR), and an admin back office to manage content, users, and reservations. Use a clean architecture, role-based access, and a database schema that supports future growth.

Roles

Admin: full control; manage content, users, events, base ticket price, delete posts/plays, hide gallery.

Monitor/Teacher: create/manage/delete their own plays/events.

Registered User (Spectator): log in, reserve tickets, download PDFs, receive emails, manage profile.

Public Visitor: view news (blog), plays, optional gallery, and contact form.

Key Features

Landing Page as Blog

/ shows latest posts (Spanish content).

Post CRUD (admin/monitor).

Hide/show posts.

Event & Play Management

Create/edit/delete plays (admin + monitor).

Upload posters, descriptions, date/time, base ticket price (€5 default).

Event detail pages.

Ticket Reservations

Logged-in users reserve seats.

Ticket PDF generated with QR code.

QR validation endpoint for entry checks.

Base price shown (no payments processed).

User Registration & Authentication

Registration must be independent from Replit’s auth.

Options:

Sign up/sign in with email + password.

Password reset flow (email).

RBAC enforced for all roles.

User & Role Management

All emails sent from admin@... via Google connection.

Admin Panel

Manage posts, plays/events, users, gallery.

News/blog

Tech Guidelines

Frontend: React (with Router), TypeScript, Tailwind CSS.

Backend: Node.js + Express, TypeScript, Prisma ORM.

DB: PostgreSQL (SQLite for dev).

Auth: JWT with roles (admin, monitor, user, public).

Infra: Docker, .env, ESLint, Prettier, tests.

Accessibility & SEO: WCAG 2.2 AA, Core Web Vitals, metadata for SEO.

Languages: Spanish default, ready for English.

Database Models
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  password  String?
  googleId  String?   // for OAuth login
  name      String
  role      Role     @default(USER)
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt
}
enum Role { ADMIN MONITOR USER }

model Post {
  id        String   @id @default(cuid())
  title     String
  body      Json
  status    String   @default("published")
  createdBy String
  createdAt DateTime @default(now())
}

model Play {
  id          String   @id @default(cuid())
  title       String
  description String
  posterUrl   String?
  dateTime    DateTime
  basePrice   Float    @default(5.0)
  createdBy   String
  createdAt   DateTime @default(now())
}

model Ticket {
  id        String   @id @default(cuid())
  userId    String
  playId    String
  qrCode    String
  createdAt DateTime @default(now())
}
